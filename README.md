# 🥊 마이 복싱 코치

혼자서도 복싱 훈련이 가능한 웹 기반 미트 트레이닝 도구입니다.  
실제 사운드를 기반으로 한 랜덤/고정 루틴을 통해 아마추어 스타일 훈련을 반복할 수 있습니다.

---

##  주요 기능
-  **음성 기반 복싱 루틴** 자동 실행
-  **2분 타이머** + 남은 시간 표시
-  **템포 조절 기능** (BPM 슬라이더)
-  **랜덤 루틴** (잽, 훅, 슥빡 등 아마추어 동작)
-  모바일 친화적인 레이아웃

---

## 🛠 기술 스택
- HTML5 / CSS3
- JavaScript

---

##  실행 방법

1. 이 저장소를 클론하거나 다운로드합니다.
2. `/sounds` 폴더에 mp3 음성 파일을 추가하세요. (`잽.mp3`, `투.mp3` 등)
3. `index.html` 또는 `drill.html` 파일을 브라우저에서 열어 실행합니다.
