DOM의 기초

      • Dom과 Dom 트리

      Dom이란? 웹 문서에 접근, 제어할 수 있도록 각각 객체로 정의 된 '문서 객체 모델'
      property와 method를 가짐
      DOM 트리는 웹 문서의 구조를 보면 됨.

      웹 요소에 접근하기

      querySelector() 함수는 하나의 웹 요소에 접근할 수 있다.
      선택자 기능 사용 예
      타입 선택자 특정 태그를 사용한 모든 요소 p{...}
      class 선택자 클래스명을 사용하는 특정 부분 .accent{...}
      id 선택자 id명을 사용하는 특정 부분 #container{...}
      하위 선택자 A요소의 하위에 있는 모든 B요소 form input{...}
      자식 선택자 a요소의 하위에 있는 요소 중 자식 레벨의 B요소 ul > li {...}

      css선택자 종류는 위와 같으며 웹 요소에 접근할 떄는 querySelector() 나 querySelectorAll()
      예시 document.querySelector("#container")
      //h1,img 같은 타입선택자 입력 가능
      //querySelectorAll(".user")[2] //이처럼 클래스 선택자 all로 선택시 전체선택
      혹은 [2]이처럼 배열로 반환받는 데 배열 수를 선택해서 특정 값만 반환을 받을 수 있음
      웹 요소의 내용 가져오기
      웹 요소.innerText
      웹 요소.innerHTML
      웹 요소.textContent
      이미지 요소.src
      div태그로 감싸진 id선택자 decs에는 p태그는 1개는 기본, displaynone2개 일 때
      document.querySelector("#desc").innerText //p class = "user" 이름 : 도레미\n 이렇게 출력
      document.querySelector("#desc").textContent //이름 : 도레미\n 이렇게 작성 됨

      웹 요소의 내용 수정하기
      웹 요소.innerText = 내용
      이미지 요소.src = 이미지 파일

      }

      자바스크립트로 스타일 수정하기

      css 속성에 접근하고 수정하기
      요소.style.속성명
      const title = document.querySelector("#title");
      title.onclick = () =>{
      title.style.backgroundColor = "black";
      title.style.color = "white";
      }
      classList 프로퍼티 살펴보기
      classList는 dom에서 자주 사용하는 프로퍼티
      p class = "user click"> 처럼 클래스 스타일을 2개 동시에 적용
      document.querySelector("#desc p").classList //배열로 0:"user" 1:"click" 이렇게 출력

      클래스 스타일 추가하고 삭제하기
      요소.classList.add(클래스명)
      요소.classList.remove(클래스명)
      스타일에 .click{...}을 선언한 뒤
      const title = document.querySelector("#title");
      title.onclick = () =>{
      title.classList.add("clicked");
      }
      이렇게 하면 실제 클릭할 경우 해당 스타일이 추가된다.
      특정 클래스 스타일이 있는 요소를 찾아 주는 contains()함수
      요소.classList.contains(클래스명); const title = document.querySelector("#title");
      title.onclick = () =>{
      if(!title.classList.contains("clicked")){//clicked 스타일이 없으면
      title.classList.add("clicked")//스타일 추가
      }else{//있으면
      title.classList.remove("clicked")//스타일 제거
      };
      }
      클래스 스타일 토글하기
      요소.classList.toggle(클래스명)
      const bttn = document.querySelector("button");
      bttn.onclick = () =>{
      document.body.classList.toggle("dark");//이렇게 클릭하면 다크모드로 바뀌게 할 수있음
      }//물론 dark 스타일이 미리 정의가 되어 있어야함

      DOM에서 폼 다루기

      id나 class 속성값을 사용해 폼 요소에 접근하기
      document.querySelector("#order-name")
      텍스트 필드에 입력한 값 가져오기 (요소.value)
      document.querySelector("#order-name").value
      name 속성값을 사용해 폼 요소에 접근하기
      document.order.product.value
      폼 배열을 사용해 폼 요소에 접근하기
      document.forms//모든 form을 가져옴
      document.forms[n].element//첫번째 form에 있는 폼 요소를 모두 가져옴
      document.forms[n].element[1]//첫번째 form에 있는 두번째 폼 요소를 모두 가져옴
      선택 목록에 접근하기
      document.querySelector("#major")//메이저 라는 아이디 값 안에 모든 목록 접근
      document.querySelector("#major").options//options프로퍼티를 사용하는 모든 값 을 가져옴
      알림 창에서 선택한 항목 표시하기 const selectMenu = document.querySelector("#major");//선택목록을 가져옴
      function displaySelect(){//매서드 선언
      let selectedText = selectMenu.options[selectMenu.selectedIndex].innerText;
      alert(`[${selectedMenu}를 선택했습니다.]`)
      }
      selectedMenu.onchange = displaySelect;

      라디오 버튼과 체크 박스에 접근
      //예문에는 폼의 name은 testForm, 라디오 박스를 name을 subject, 벨류는 speaking,grammar, writing이다.
      document.testForm.subject//배열로 입력됨.
      document.testForm.subject[1].value//grammar를 가져옴
      checked 속성을 사용해 선택한 항목에 접근하기
      라디오 버튼이나 체크박스에는 checked라는 속성이 있어 체크 여부로 (true) 웹 요소에 접근할 수 있음
      document.querySelector("input[name='subject']:checked")
